# 🌟 Glassmorphism Login Form

> Uma interface de login moderna, elegante e 100% responsiva construída apenas com HTML5 e CSS3 puro. O foco deste projeto foi aplicar o conceito de UI Design conhecido como **Glassmorphism** (efeito de vidro fosco).

Demonstração da Aplicação https://telalogi.netlify.app/


## 🛠️ Tecnologias Utilizadas

Este projeto é um componente de front-end puro, sem a necessidade de frameworks pesados, provando o domínio das linguagens base da web.

- **HTML5** - Estruturação semântica do formulário.
- **CSS3** - Estilização, layout (Flexbox) e responsividade.
- **Boxicons** - Biblioteca de ícones (inserida via CDN).

## ✨ Principais Funcionalidades e Destaques Visuais

- **Efeito Glassmorphism:** Uso da propriedade CSS `backdrop-filter: blur()` combinada com bordas e fundos semi-transparentes para criar o aspecto de vidro sobreposto a uma imagem.
- **Totalmente Responsivo:** O layout se adapta perfeitamente a telas de smartphones (Mobile First) graças ao uso de Media Queries (`@media (max-width: 480px)`).
- **UX/UI Aprimorado:** Transições suaves (`transition: 0.5s`) em botões e links para melhor feedback visual ao usuário (Hover effects).
- **Inputs Customizados:** Estilização profunda de campos de texto, placeholders e checkboxes, fugindo do padrão engessado dos navegadores.
